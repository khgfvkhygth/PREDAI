# Bustabit Real-Time Multiplier Predictor

🔮 This project uses OCR to capture Bustabit multipliers live from the screen and predict trends like ICE ZONES, REBOUND chances, and 10x+ events — all in real-time.

## 📦 Features

- Real-time multiplier capture from screen using Tesseract OCR
- Live CSV logging
- Flask web dashboard with:
  - Trend chart
  - Current volatility zone
  - 10x+ prediction

---

## ⚙️ Requirements

- Python 3.8+
- Tesseract OCR (install from https://github.com/tesseract-ocr/tesseract)
